# Archive 2.1.0

2026-10-19. 발표를 위해 사용자가 공식 배포를 직접 요청했다. 다음 업데이트부터는 미리보기 링크 확인 → 사용자 확인 → 공식 배포 순서로 진행한다.

- Years: 연도별 작품 수에 따라 크기가 달라지지 않도록 PC 4열, 작은 화면 3열·2열을 사용한다. 작품 비율과 연도 안의 순서를 보존한다.
- Sequences: 왼쪽에서 오른쪽으로 이어지는 수평선과 같은 단계의 가지를 표시한다. 초기 작품 배치는 제작연도 오름차순, 같은 연도는 Years 순서다. 관리자는 썸네일을 끌거나 방향키로 위치를 저장한다. 위치는 선택한 흐름 안에 저장하며 다른 보기 순서와 독립적이다. 제작연도는 최초 배치용이며 이후 의미의 순서를 직접 정한다.
- 그룹 관리: 그룹 목록·관계 미리보기·선택 그룹 편집을 분리한다. 그룹 소속 편집과 수동 연결선 편집을 구분하고, 소속 변경 때 수동 연결을 보존한다. 그룹과 단계 삭제는 작품 삭제와 별개다.
- 방문자 관계 강조: 작품이 직접 속한 모든 그룹의 작품·선을 강조한다. 연결된 다른 그룹으로 재귀 확장하지 않는다. 생태계의 주변 확대 미리보기와 클릭 상세 팝업은 유지한다. 천체는 작품 대표색을 유지한다.
- TEXTS: 한국어·영어 탭과 선택형 나란히 비교. 새 문단은 한국어 18px, 영어 20px, 줄간격 160%, 문단 간격 1em이다. 저장된 사용자 글자 크기는 보존한다. 편집 도구 크기는 pt로 표시하며 저장할 때 기존 px 형식으로 환산한다.
- 공통 글꼴: 영문 Cormorant Garamond, 한글 Noto Sans KR. TEXTS 본문은 영문 Cormorant Garamond, 한글 나눔명조. 기존 백색 배경 #F5F5F5를 유지한다.
- 글꼴은 공식 Google Fonts 배포본을 WOFF2로 변환해 사이트에서 직접 제공한다. 배포 시 외부 글꼴 응답을 분석하다 실패하는 문제를 피하며, 파일 내용 해시가 든 주소와 장기 캐시를 사용한다. SIL 라이선스를 함께 보관한다.
- 기존 관리자 비밀번호, 운영 저장소, 작품·그룹·글·PDF는 교체하거나 초기화하지 않는다. 배포는 새 선택 항목이 없는 기존 문서도 읽을 수 있다.
