# 2.3.0 검토본

공식 배포 승인 전 단계다. 이번 작업은 검토용 브랜치와 미리보기에서만 제공한다.

## 변경

- 작품 보기 메뉴: 글씨 색 전환, 높이 30px·반지름 15px의 시각 캡슐, 최소 44px의 클릭 영역, 글자 외형에 맞춘 세로 정렬.
- 생태계·천체: 작품에서 벗어난 뒤 1초 유지. 다른 작품은 즉시 표시하고 그룹 강조도 함께 전환. 분류 이동 때 예약 정리.
- 배치 설정: 세계관에 맞춘 짧은 이름과 상대 강도 %. 물리 연산 범위와 기본값은 보존.
- 돋보기: 실제 object-contain 이미지 영역 기준 좌표, 가장자리 부호 오류 수정, 렌즈 이동과 표본 위치 분리, 반응형 크기, 로딩·크기 변경 때 정리. 터치 이동·두 손가락 조작 시 길게 누르기 취소.
- Contact: 기존 메일 주소 링크와 문의 폼을 유지하며 주소 복사와 실패 안내 추가.
- 관리자 방문 통계: 일·월·연 추이와 기간 고유 방문자·세션·페이지 조회 보고서. 서버 인증, 시간당 캐시, 한국 시간, 이전 경과 기간 비교, 오류/미설정/0 구분. 관리자 로그인 브라우저 기본 제외와 로그아웃 뒤 유지.
- 규모 점검: 200개 이하 천체·생태계 계산 보존. 큰 목록에서는 천체 원거리 근사 계산과 생태계 근처 사각형 탐색을 사용. 큰 생태계는 작은 썸네일 사용. 원본은 상세에서 요청.

## CV 통합 편집 계획 · 마지막 검토용 / 구현 전

사용자 요청: CV 한 화면에서 신규 기록 추가·기존 기록 수정·삭제·순서를 관리한다. 이번 단계는 계획만 기록하며 코드나 공식 자료는 변경하지 않는다.

- 학력, 개인전, 단체전, 팝업 전시, 프로젝트, 레지던시, 펠로십, 수상, 출판의 각 제목 옆에 ‘＋ 기록 추가’를 둔다. 기존 행에는 ‘수정’과 ‘삭제’, 위/아래 이동을 둔다. 섹션 순서와 기록 순서는 별개로 표시한다.
- 기록 편집에는 기간 공통 필드와 한글/영문 입력란을 둔다. 제목·기관·장소 등은 기존 자료 형식을 유지한다. 드래그 외에 이동 버튼을 제공한다. 편집 중에는 기록의 정체성을 ID로 유지한다.
- 한 화면이지만 저장 단위를 명확히 한다. 기록 편집은 기록별 저장/취소, 순서 편집은 별도 저장으로 구분한다. 편집 중 다른 기록·메뉴로 이동하면 화면 내 안내에서 저장/계속 편집/변경 취소를 선택한다. 사용자의 선택 전에는 이동하지 않는다.
- 기존 CV 내용은 저장 시 공개 화면에 반영되는 구조다. 버튼 근처에 적용 범위를 표시하고, 입력 중인 내용은 저장 전까지 공개하지 않는다. 작품 분류의 임시저장/공개 흐름과 혼동하지 않게 안내한다.
- ‘작가정보 · 전시 · 뉴스’의 중복 CV 입력란은 통합 CV로 연결하고, 소개문·연락처·뉴스는 원래 화면에 둔다. 전시 자료는 기존 전시 목록과 동일한 기록을 사용하며 복제하지 않는다. 전시의 관련 링크 등 기존 필드도 보존한다.

### 확인된 위험과 대응

1. 구형 AboutForm은 CV 배열을 함께 전송하고 revision 없이 저장한다. 다른 창에서 수정한 배열을 덮어쓸 수 있다. 통합 저장은 변경한 필드만 다루고 버전 검사를 필수로 하며, 오래 열린 편집에는 입력을 유지한 채 충돌 안내를 표시한다. 남아 있는 구형 저장 경로도 함께 점검한다.
2. About과 exhibitions는 서로 다른 문서다. 현재 단일 ‘CV 저장’과 전시별 저장을 혼합하면 일부 성공/일부 실패를 숨길 수 있다. 기록별 저장 단위를 유지하고, 저장 완료와 화면 갱신 실패를 구분한다. 성공한 전시 추가를 재시도하며 중복 생성하지 않게 처리한다. 서버 실패를 무조건 미저장으로 간주하지 않는다.
3. 기존 AboutForm은 연도와 한글 본문이 없는 행을 filter로 제거한다. 새 편집기는 불완전한 행을 조용히 삭제하지 않고 오류 위치를 알려 입력을 보존한다. 한 언어만 있는 기존 기록도 유지하며 공개 화면의 빈 번역 처리 정책을 검증한다.
4. 번호 기반 이동은 수정/삭제 후 다른 행을 가리킬 수 있다. 기록 ID와 정렬 순서를 분리하고 전시 유형 변경·새 항목 추가·삭제 뒤에도 누락/중복 없는지 확인한다. 프로젝트 추가에만 해당하는 기존 편집 로직을 전체 항목에 무작정 재사용하지 않는다.
5. 삭제는 저장 전 취소 가능하게 하고, 저장된 삭제도 복구 가능한 자료를 유지한다. 섹션 전체와 개별 기록 삭제를 혼동하지 않게 한다.
6. ‘2026~’, 기간, 동일 연도 여러 기록과 한/영문 짝, 사용자 지정 순서를 보존한다. 자동 연도 정렬을 강제하지 않는다. 빈 섹션은 관리자에서 추가할 수 있도록 남기고 공개 화면에서는 빈 제목을 숨긴다.

### 구현 후 배포 전 검사

- 분리된 시험 자료로 9종 기록 추가/수정/삭제/복구, 두 언어 보존, 섹션/행 이동, 재접속 후 저장 결과를 확인한다. 공식 자료로 시험 기록을 만들지 않는다.
- 두 관리자 창의 충돌, 저장 버튼 연속 클릭, 연결 실패, 저장 성공 후 공개 캐시 갱신 실패를 시험한다. 새 기록 중복·부분 성공·기존 기록 손실이 없는지 비교한다.
- 공개 CV와 전시 목록에서 같은 변경을 확인하고 관련 링크·개인정보·작가소개가 의도치 않게 바뀌지 않는지 검사한다. 좁은 화면의 입력과 이동 버튼도 확인한다.
- 기존 2.3.0 검사 결과 38개는 CV 신규 기능 검증을 포함하지 않는다. 구현 후 변경 범위에 맞춰 검사와 빌드를 다시 수행한다.
- 실제 스마트폰 돋보기/스크롤 검사는 남아 있다. 1,000개 점검은 모의 자료의 계산 검사이며 실제 기기 속도·요금 한도를 보장하지 않는다.
- 검토 자료와 최신 공식 자료는 다를 수 있다. 코드를 배포하더라도 검토용 작품·분류·CV를 공식 자료에 덮어쓰지 않는다. 공식 배포와 통계 수집 시작은 별도 승인 후 진행한다.
